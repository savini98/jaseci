- **Feature: ContextRender context management for tool-calling agents**: Passing `context=Context(budget_tokens=N)` to `by llm()` records every message and tool result of the ReAct loop into a `ContextGraph` and, before each model call, renders the tool results down to a token budget without deleting anything. Results are scored by recency, by how often later turns reused their identifiers, and by relevance to the agent's current focus, then selected with an MMR diversity penalty; unselected results become short, restorable stubs (smart trim or identifier-dense micro stub) whose bytes stay stable across turns, and a result comes back in full when it becomes useful again. When the history still crosses the auto-compaction threshold, a wired `Context` replaces the prose summary with a typed-slot `CompactionSlots` extraction that copies values verbatim. New `[plugins.byllm.context]` settings (`budget_tokens`, `budget_ratio`, `embed_model`), new exports `Context`, `ContextRender`, `ContextGraph`, `ContextToolResult`, `ContextMessage`, `ContextCompactionSummary`, `CompactionSlots`, and a "Context Management (ContextRender)" section in the byLLM reference. Nothing changes for calls that do not pass `context`.
